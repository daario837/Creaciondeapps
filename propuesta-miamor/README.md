# Propuesta para miamor ❤️

Mini web para que Sara elija cómo será la cita del sábado y descubra el itinerario final.

- `propuesta.html`: fuente del artefacto publicado en claude.ai (las respuestas se guardan en su base de datos y el propietario las ve al final de la portada).
- `index.html`: la misma página como HTML independiente (GitHub Pages u otro hosting). Sin base de datos: las respuestas se envían por WhatsApp o copiando el resumen.

Si se cambia `propuesta.html`, regenera `index.html` envolviéndolo en el `<html>/<head>/<body>` que tiene arriba.
